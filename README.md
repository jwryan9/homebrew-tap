# Jwryan9 Tap

## How do I install these formulae?

`brew install jwryan9/tap/<formula>`

Or `brew tap jwryan9/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jwryan9/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
