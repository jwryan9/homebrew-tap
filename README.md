# Jwryan9 Tap

## How do I install these casks?

`brew install --cask jwryan9/tap/<cask>`

Or `brew tap jwryan9/tap` and then `brew install --cask <cask>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jwryan9/tap"
cask "<cask>"
```
